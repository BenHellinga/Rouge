# Rouge

**This project is no longer under active development.**

## About

This was probably the first serious project I ever did, back in grade 10 programming class for the "game unit" in 2019. I'd seen Rogue, the classic ASCII dungeon crawler, and wanted to try recreating it myself: randomly generated rooms, a movable character, sightlines, enemies that move around, random items, and more.

I had no idea what I was doing at the time, so the code is super spaghetti and full of bad practices (global variables everywhere, functions that return grab-bag lists, you name it). I'm not planning on cleaning it up or writing a usage guide, this is just here so it isn't lost and I can look back at it someday.

Also, I meant to name it "Rogue" and misspelled it "Rouge", and didn't notice until after I'd already submitted it for the assignment. The name stuck.
